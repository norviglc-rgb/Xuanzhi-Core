# COZE_STUDIO_INTEGRATION.md

## 1. 文档目的
定义 Coze Studio 在 Xuanzhi-Core 系统中的角色、边界、接入方式与当前状态。

---

## 2. 组件定位
Coze Studio 是当前系统中的**AI 应用中枢**。

它负责：
- 承载 AI 应用
- 组织应用层 agent / flow
- 提供用户侧或业务侧应用入口
- 作为部分 AI 场景的前台应用平面

---

## 3. 与 Xuanzhi-Core 的关系
Xuanzhi-Core 是治理中枢；
Coze Studio 是 AI 应用承载平面。

两者关系是：
- Xuanzhi-Core 负责治理、边界、风险与结果收敛
- Coze Studio 负责应用层组织与交互承载

---

## 4. 边界
Coze Studio 不负责：
- 项目宪章与边界定义
- 全局风险和审批规则源头定义
- 根层治理策略
- 项目整体变更控制

---

## 5. 输入输出关系
输入可能包括：
- 用户场景请求
- 业务侧应用调用
- 与检索、模型层协作的应用任务

输出包括：
- 应用结果
- 事件或中间状态
- 可回传治理层的结果信息

---

## 6. 当前状态
当前系统已明确将 Coze Studio 作为核心组件之一纳入基线技术栈。
