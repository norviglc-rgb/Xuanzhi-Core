# COZE_STUDIO_INTEGRATION.md

## 1. 文档目的
定义 Coze Studio 在 Xuanzhi-Core 系统中的角色、边界、接入方式与当前状态。

---

## 2. 组件定位
Coze Studio 是当前系统中的**AI 应用中枢**。

它负责：
- 承载 AI 应用
- 组织应用层 agent / flow
- 提供用户侧或业务侧应用入口
- 作为部分 AI 场景的前台应用平面

---

## 3. 与 Xuanzhi-Core 的关系
Xuanzhi-Core 是治理中枢；
Coze Studio 是 AI 应用承载平面。

两者关系是：
- Xuanzhi-Core 负责治理、边界、风险与结果收敛
- Coze Studio 负责应用层组织与交互承载

---

## 4. 边界
Coze Studio 不负责：
- 项目宪章与边界定义
- 全局风险和审批规则源头定义
- 根层治理策略
- 项目整体变更控制

---

## 5. 输入输出关系

### 5.1 输入来源
- 用户场景请求
- 业务侧应用调用
- 与检索、模型层协作的应用任务
- 来自 n8n 的自动化触发

### 5.2 输出内容
- 应用结果
- 事件或中间状态
- 可回传治理层的结果信息

---

## 6. 接入路径

### 6.1 模型调用路径
```
Coze Studio 应用
  -> Higress API Gateway
    -> 路由到指定模型（Claude/GPT/本地模型）
      -> 返回结果
```

### 6.2 检索调用路径
```
Coze Studio 应用
  -> QMD 检索服务
    -> 返回相关上下文
      -> 结合模型生成回答
```

### 6.3 治理层回传路径
```
Coze Studio 应用执行完成
  -> 通过 Webhook/API 回传结果
    -> Xuanzhi-Core 记录
      -> 必要时触发后续流程
```

---

## 7. 应用分类方式

### 7.1 按用途分类
| 类别 | 说明 | 示例 |
|------|------|------|
| assistant | 通用助手类应用 | 编程助手、写作助手 |
| workflow | 流程执行类应用 | 自动化报告生成 |
| knowledge | 知识问答类应用 | 文档问答、FAQ |
| creative | 创意生成类应用 | 内容创作、头脑风暴 |

### 7.2 按风险等级分类
| 风险等级 | 应用类型 | 治理要求 |
|---------|---------|---------|
| R0/R1 | 只读查询、信息检索 | 无需审批 |
| R2 | 内容生成、简单自动化 | 治理级审批 |
| R3 | 系统集成、外部调用 | 人工审批 |

---

## 8. 与其他组件的调用边界

### 8.1 与 Higress 的边界
- Coze Studio 通过 Higress 访问所有模型
- 不直接调用模型 API
- 模型配置由 Higress 统一管理

### 8.2 与 n8n 的边界
- n8n 可以触发 Coze Studio 应用执行
- Coze Studio 不主动触发 n8n 流程
- 复杂编排由 n8n 负责

### 8.3 与 NocoBase 的边界
- NocoBase 提供配置管理后台
- Coze Studio 可读取 NocoBase 中的配置
- 审批流程由 NocoBase 承载

### 8.4 与 QMD 的边界
- QMD 提供检索能力
- Coze Studio 按需调用 QMD
- 检索策略由应用层决定

---

## 9. 示例场景链路

### 9.1 文档问答场景
```
用户提问
  -> Coze Studio 应用接收
    -> 调用 QMD 检索相关文档
      -> 通过 Higress 调用模型生成回答
        -> 返回用户
          -> 记录到 Xuanzhi-Core（可选）
```

### 9.2 自动化报告场景
```
n8n 定时触发
  -> 调用 Coze Studio 报告生成应用
    -> 应用收集数据
      -> 通过 Higress 调用模型生成报告
        -> 返回结果给 n8n
          -> n8n 分发报告
            -> 记录到 Xuanzhi-Core
```
