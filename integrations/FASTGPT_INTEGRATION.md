# FASTGPT_INTEGRATION.md

## 1. 文档目的
定义 FastGPT 在 Xuanzhi-Core 系统中的角色、边界、接入方式与当前状态。

---

## 2. 组件定位
FastGPT 是当前系统中的**知识库问答与对话应用平台**。

它负责：
- 知识库管理
- 基于知识库的问答应用
- 对话式 AI 应用承载
- RAG（检索增强生成）场景支持

---

## 3. 与 Xuanzhi-Core 的关系
Xuanzhi-Core 负责治理与收敛；
FastGPT 负责知识库问答应用的执行。

两者关系是：
- Xuanzhi-Core 定义知识库应用的治理边界
- FastGPT 承载具体的知识库问答应用
- 应用执行结果可回传 Xuanzhi-Core 记录

---

## 4. 边界
FastGPT 不负责：
- 项目宪章与边界定义
- 全局风险和审批规则源头定义
- 根层治理策略

---

## 5. 输入输出关系

### 5.1 输入来源
- 用户知识库问答请求
- 来自业务系统的 API 调用
- 来自 n8n 的自动化触发

### 5.2 输出内容
- 问答结果
- 对话记录
- 可回传治理层的使用统计

---

## 6. 与其他组件的协作

### 6.1 与 Higress 的协作
- FastGPT 通过 Higress 访问模型能力
- 不直接调用模型 API

### 6.2 与 QMD 的协作
- FastGPT 可调用 QMD 进行检索
- 或使用内置的知识库检索能力
