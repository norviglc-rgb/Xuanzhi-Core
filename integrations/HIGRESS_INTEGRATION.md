# HIGRESS_INTEGRATION.md

## 1. 文档目的
定义 Higress 在 Xuanzhi-Core 系统中的角色、边界、接入方式与当前状态。

---

## 2. 组件定位
Higress 是当前系统中的**模型入口网关 / 路由层**。

它负责：
- 统一模型访问入口
- 模型路由与代理
- 鉴权、网关策略、流量治理
- 为 AI 执行层提供统一模型接入面

---

## 3. 与 Xuanzhi-Core 的关系
Xuanzhi-Core 负责治理与路由决策；
Higress 负责模型访问入口与流量控制。

两者关系是：
- Xuanzhi-Core 决定“是否需要模型能力、由哪类路径触发”
- Higress 负责“模型入口如何被统一访问和治理”

---

## 4. 边界
Higress 不负责：
- 项目目标定义
- 风险规则定义
- 审批策略定义
- 工作流治理定义

这些仍属于 Xuanzhi-Core 的治理层。

---

## 5. 输入输出关系
输入可能包括：
- 来自 Coze Studio 的模型请求
- 来自 Claude Code 相关链路的模型调用
- 来自自动化流程的模型能力请求

输出包括：
- 统一模型调用结果
- 路由 / 网关层返回信息
- 可供治理层记录的调用结果或状态

---

## 6. 当前状态
当前系统已明确：
- 旧的 `LiteLLM` 表述不再作为当前模型路由主叙事
- `Higress` 是当前应被纳入正式基线的模型入口网关
